# Git command practice

Run `git-inspection-commands.sh` from inside a repository. Run `upstream-inspection.sh` from the parent directory where you want the read-only inspection clone created. These scripts intentionally do not push to the upstream repository.

For the two-branch grading merge conflict and calculator faulty-commit exercise, follow the sequence in `REPORT.md` and keep the complete history. The ZIP includes the final, corrected source code and tests.
