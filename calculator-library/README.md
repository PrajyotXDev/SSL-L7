# Calculator Library

Functions: `add`, `subtract`, `multiply`, `divide`, and `square`. Division by zero raises `ZeroDivisionError`; invalid non-numeric inputs are rejected.

```bash
python calculator.py
python -m unittest -v
```

Git exercise: preserve a deliberately faulty `square` commit, identify it using `git log` / `git show`, then fix it in a later commit. The correct final implementation is in `calculator.py`.
